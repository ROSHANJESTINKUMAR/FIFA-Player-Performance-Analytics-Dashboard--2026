# FIFA World Cup 2026 - Player Performance Analytics Dashboard

## 📌 Project Overview
This project analyzes player performance data from the FIFA World Cup 2026 
(Kaggle dataset) using SQL for data querying and Tableau for visualization. 
The goal was to clean raw data, write analytical SQL queries, and build an 
interactive dashboard highlighting key player and team performance insights.

## 🛠️ Tools Used
- *Data Cleaning:* Microsoft Excel
- *Database:* SQLite (via DB Browser for SQLite)
- *Querying:* SQL (25 analytical queries)
- *Visualization:* Tableau Public

## 📂 Project Structure
## 📊 Key Analysis Performed
- Total players, teams, and match records overview
- Top 10 goal scorers and assist providers
- Top 10 highest rated players (by average player rating)
- Team-wise total goals and assists
- Goals scored by playing position (Forward, Midfielder, Defender, Goalkeeper)
- Market value vs. player performance rating correlation
- Average player rating across Group Stage vs. Knockout stages
- Team-wise discipline analysis (yellow/red cards)
- Goals by nationality (world map visualization)

## 🔍 Key Insights
- *Memphis Zerrouki* was the tournament's top scorer with 24 goals.
- *Turkey* led all teams with 65 total team goals.
- *Forwards* contributed the majority of goals (1,805), followed by 
  Defenders (866) and Midfielders (353); Goalkeepers scored none, as expected.
- No strong correlation was found between a player's market value and their 
  average performance rating.
